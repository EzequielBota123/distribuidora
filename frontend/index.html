Importar productos desde Excel / CSV

Columnas reconocidas: código, nombre, categoría, costo, costo USD, multiplicador, precio, stock, stock mínimo (los nombres de columna son flexibles, ej. "Precio Venta", "Costo Dólar" o "Stock Actual" también funcionan). Si cargás una columna de costo en USD, el costo en pesos se calcula solo con la cotización actual del dólar ($0) — no hace falta que la planilla tenga el costo en pesos. Si el código ya existe se actualiza el producto; si no existe, se crea uno nuevo. Descargar plantilla de ejemplo

Elegí un archivo para ver la vista previa.

✕

Importar gastos desde Excel / CSV

Columnas reconocidas: fecha, concepto, categoría (opcional, "General" si no viene), proveedor (opcional, se crea solo si no existe), y monto y/o monto USD (los nombres de columna son flexibles, ej. "Detalle", "Importe" o "Descripción" también funcionan). La fecha puede venir como fecha de Excel o como texto (DD/MM/AAAA o AAAA-MM-DD). El monto puede tener "$" y puntos de miles.
